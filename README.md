# Project Name

A simple Mars mission game made with Unreal Engine.

## 🎮 About the Project
Explain what your project is about, its main features, and the genre. 
* **Engine:** Unreal Engine 5.8
* **Platform:** Windows (64-bit)
* **Genre:** Sci-Fi / Simulation / GameJam

## 📥 Download & Installation
Since the build files are large, the compiled version is hosted in the **Releases** section.

1. Go to the Releases.
2. Download the latest `.zip` file (approx. 400 MB).
3. Extract the `.zip` archive to a folder on your computer.
4. Run .exe to start playing.

## 🕹️ Controls
Use mouse click and E key.

## 💻 System Requirements
* **OS:** Windows 10/11 (64-bit)
* **Processor:** Quad-core Intel or AMD, 2.5 GHz or faster
* **Memory:** 8 GB RAM
* **Graphics:** DirectX 12 compatible graphics card

## 🛠️ Built With
* [Unreal Engine 5.8](https://unrealengine.com)
* Blueprints / C++
